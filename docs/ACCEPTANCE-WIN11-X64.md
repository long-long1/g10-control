# 干净 Windows 11 x64 Beta 验收清单

此表是待执行清单，不是通过声明。开发机模拟、真实 VB-CABLE 合成测试及窗口生命周期结果不能代替本表。记录系统/依赖版本、标准用户、构建 manifest 哈希、操作人和日期。禁止自动安装驱动或模拟键鼠。

## 非硬件验收

- [ ] 无 Python/Node/开发目录，整体复制后主 EXE、React/CSS 和中文向导正常。
- [ ] WebView2/.NET 缺失时中文提示及日志正确；用户手动安装官方组件后恢复。
- [ ] 可写目录使用 data；真正只读 ACL 下回退 LocalAppData 并显示原因；两者不可写时明确失败。
- [ ] 前后步骤、重新检测、稍后继续和重启恢复正确，不伪标完成。
- [ ] 缺设备/驱动、权限失败、端点歧义、证明缺失/过期均有对应状态，不能绕过完成/启动门槛。
- [ ] 默认不扫描 BLE、不连接、不启动音频业务、不唤起豆包。
- [ ] 可见窗口、托盘隐藏/恢复、单实例、安全退出无残留；移动后配置/资源正确。
- [ ] 明确确认的登录启动可启用/停用；移动后提示修复，未确认不写。测试前保存当前用户原值，结束后经用户确认恢复。
- [ ] Portable 按键观察器不可用且按钮禁用，不存在可执行键鼠模拟入口。
- [ ] candidate data 初始为空；无开发机身份、日志/录音、output、.venv、node_modules、Git 历史。
- [ ] package-audit 与 manifest 通过，实际二进制哈希与记录一致。

## 单独取得硬件授权后

- [ ] 用户点击才扫描 BLE；显示真实名称/地址，无固定 VID/PID 伪装实时检测。
- [ ] 选择持久化、重选撤销证据；未知服务、缺特征、错误属性/codec/帧长均拒绝。
- [ ] 兼容性检查只有单次能力请求，无 MIC_OPEN/MIC_CLOSE；异常也恢复 CCCD 并释放对象。
- [ ] 不只看名称，不宣称未测型号支持；当前仅检查已配对且名称为 G10 的传输边界。
- [ ] VB-CABLE 空闲后，用户确认一次合成验证；实际相关性/流状态合格，无默认设备/音量变化、物理麦克风或录音文件。
- [ ] 证明保存/重启复核正确；ID/共享格式变化和 30 天过期阻止桥接。
- [ ] 明确启动真实桥接、红键和手动豆包流程通过；自动唤起保持关闭。
- [ ] 停止、托盘、退出、断线、超时和异常安全清理可靠，不强杀 BLE、不丢原订阅。

- [ ] PyWinRT、proxy_tools、PortAudio 缺失文本补齐并对应版本；WebView2 SDK/Loader 和其他 native 条款核验。
