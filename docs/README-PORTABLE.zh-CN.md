# G10 Control v0.1.0 Beta 候选版使用说明

当前目录只供本地验收。项目整体许可证和第三方再分发材料尚未完成，不能对外分发此目录或制作公开 ZIP/Release。

## 运行条件与启动

本轮变化见 `RELEASE-NOTES.zh-CN.md`。`sbom.cdx.json`、`license-inventory.json`、`build-evidence.json` 和 `manifest.json` 是候选证据；它们不代表法律或干净机验收完成。运行前的安全脚本见 `ACCEPTANCE-WIN11-X64.md`。

应用设置损坏时会显示安全默认值和恢复提示；原文件保留，可重试读取或在「软件设置」恢复默认值，先导出诊断。设备配置损坏时不会启动桥接；用户重新扫描并选择设备后，原件保存在本机 `local-settings.json.corrupt-*`，必须重新检查兼容性。备份可能含个人身份，不要上传。诊断导出不包含录音，但可能含设备身份、路径及日志，分享前检查。

- Windows 11 x64，标准用户权限。
- 已安装 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.6.2 或更新版本；缺失时由用户自行安装官方版本，本程序不自动安装。
- 音频功能需要用户自行安装官方标准 VB-CABLE，并在 Windows 中预先配对受支持 G10。
- 候选目录自带 Python 运行时和静态前端，设计上不需要安装 Python/Node；开发机测试不等于干净电脑验收。

不要只复制 EXE。保留两个 EXE、`_internal` 和 `portable.marker`，双击 `G10-Control.exe`。`G10-AudioBridge.exe` 由主程序管理，无需手工运行。

## 首次配置

1. **欢迎与环境**：点击检测，查看 Windows、.NET、WebView2 状态和实际数据目录。
2. **蓝牙设备**：先在 Windows 配对 G10，再点击扫描、选择自己的地址。名称和广播服务不表示兼容。兼容性检查需单独确认：连接选中设备、订阅并恢复通知、发送一次能力请求，不发送开麦命令。请勿按红键。
3. **虚拟端点**：点击检测 VB-CABLE。播放端是 **CABLE Input**（本程序写入），录音端是 **CABLE Output**（豆包等软件读取），两端均需 48 kHz、双声道共享格式。重复、失活、静音、零音量或信息不可读时拒绝，不回退到其他设备。
4. **合成验证**：先停止其他软件向虚拟通道送入真实麦克风或私人音频。明确确认后检查会话空闲，发送约 1.48 秒低幅度合成信号，短暂读取虚拟录音端至内存。不打开物理麦克风、不保存录音、不更改默认设备或音量。无法确认空闲时先关闭相关程序，再重新检测和确认。
5. **完成**：环境、设备协议兼容性和当前路由证明全部通过才能完成。支持返回、重测、“稍后继续”和退出后继续；过期或未复核状态不会自动成功。

当前沿用已验证传输边界：只检查 Windows 已配对且名称为 G10 的候选，仍必须满足实际 ATVV 服务、特征属性、codec 2 / 128 字节能力。不能保证任意标为 G10/3K 的型号均支持；其他名称或协议会拒绝。本轮蓝牙发现和兼容性仅做模拟测试，真实设备验收仍待单独确认。

## 手动使用豆包

1. 在豆包输入法内手动选择 **CABLE Output** 录音端。
2. 在主程序明确启动 G10 服务；证明或兼容性配置无效时拒绝启动。
3. 手动开启豆包语音，再按住 G10 红键说话、松开结束。

自动唤起仍是默认关闭、未通过实机验收的实验功能，建议保持关闭。程序不会替用户自动开启豆包录音。

## 数据、移动与退出

- 有 `portable.marker` 且可写时，设置、日志、设备配置、路由证明和向导进度位于 EXE 同级 `data`。
- 不可写时回退 `%LOCALAPPDATA%\G10Control`，向导显示路径和原因；切换数据根不会静默迁移身份或证明。
- 设备能力证据和路由证明有效期均为 30 天。ID/格式变化、文件缺失/损坏、版本变化或过期需重新检查；重启后也复核状态。
- 移动前先安全退出，整体移动程序目录。Windows 可能短暂保留文件句柄，可稍后重试，切勿在运行中移动。
- 关闭窗口默认隐藏至托盘；托盘可打开或安全退出。清理未完成时保持窗口供重试，不强杀蓝牙进程。
- 登录启动必须用户确认。目录移动后在设置页确认修复路径；程序不擅自写注册表。
- 此候选版未打包按键观察器，页面显示不可用；不提供键鼠模拟、自定义映射或驱动安装。

## 常见问题

- **未发现设备/权限失败**：检查蓝牙开关、Windows 配对和权限，再手动扫描；扫描失败不等于协议不兼容。
- **兼容性失败**：确认地址、在线状态，不按红键；未知服务或能力不放行。清理失败先查看日志，不连续重试硬件操作。
- **VB-CABLE 缺失/重复**：自行检查官方驱动和端点；不会选物理麦克风或其他虚拟驱动替代。
- **采样率/音量/静音不符**：用户手动处理后重测，程序不改系统设置。
- **路由失败/通道占用**：关闭占用软件后重新确认，名称匹配不等于路由成功。
- **WebView2/.NET 缺失**：启动错误框与数据目录日志给出手动处理说明，不自动下载安装。
- **目录权限失败**：查看实际数据路径；Portable 和 LocalAppData 均不可写时须修复权限后再启动。

导出诊断前请自行检查报告；地址、端点 ID、本机路径属于本地资料，不要直接公开。默认不保存录音，日志和 JSON 也不会自动上传。


开发者复建：在隔离 `.venv` 安装 `requirements-build.lock.txt`，执行 `powershell -NoProfile -File build/build_portable.ps1`。第二份可指定 `-DistPath output/rebuild -WorkPath output/rebuild-work`；用 `build/compare_builds.py` 比较两份 payload。脚本固定 hash seed 和当前源提交的 PE 时间，只作用于构建进程；跨机器/工具版本的可重复性仍需另验。完整 SBOM 是构建/运行依赖超集，静态链接原生子组件审查未完成。
