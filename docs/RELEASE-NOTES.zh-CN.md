# G10 Control v0.1.0 Beta 本地验收候选（2026-10-20）

基于 9623cc9 候选继续完善；仅生成本地目录，没有公开 ZIP 或 Release。

- 修复桥接退出、断连、状态文件损坏、心跳过期或未来时间戳仍显示音频活跃的问题。异常不会自动启动业务，也不会强杀桥接。
- 损坏的应用设置保留原文件，使用安全默认值并显示中文恢复提示；诊断记录该提示。损坏的设备配置不会阻断桌面导入；用户重新扫描并选择设备时备份损坏原件，再重新验证兼容性。
- 增加离线异常/恢复回归，覆盖设备身份、证明过期、端点变化、缺 WebView2/VB-CABLE、启动失败及停止超时。
- 新增完整构建环境版本快照、CycloneDX SBOM、实际原生文件/许可文本哈希和锁文件核对；本地验收脚本不依赖 Python/Node、不安装/卸载软件、不修改系统设置。

已验证的 BLE/ATVV、ADPCM、WASAPI 核心保持原实现。本轮不执行真实硬件业务。必须手动开启豆包语音输入；自动唤起未通过，冻结版按键观察器不可用。
